# Sight Reader

A Vite + React + TypeScript app for practicing music sight reading with VexFlow 5.

## Stack

- pnpm 11
- Vite 8
- React 19
- TypeScript
- VexFlow 5

## Scripts

```bash
pnpm install
pnpm dev
pnpm test:run
pnpm build
```

For Vercel, use `pnpm build` as the build command and `dist` as the output directory.
